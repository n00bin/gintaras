Every level needs teaching, supported practice, independent application, feedback and assessment in listening, reading, spoken interaction, spoken production and writing. Mediation and communication strategies should connect these skills: summarise for someone, clarify a misunderstanding, adapt a message to a recipient, or combine information from sources.

Use the [Council of Europe global scale](https://www.coe.int/en/web/common-european-framework-reference-languages/table-%201-cefr-3.3-common-reference-levels-global-scale) and [Companion volume](https://rm.coe.int/cefr-companion-volume-with-new-descriptors-2020/16809ea0d4) for descriptor selection and assessment design. The following activities are Wordami design proposals, not official CEFR examinations.

| Stage | Intended learning direction | Example activity families |
| --- | --- | --- |
| A1 | Supported communication about personal needs | Introductions, simple messages, prices, ordering, finding a place; short recordings and documents |
| A2 | Routine everyday interaction with increasing independence | Make arrangements, describe routines, compare purchases, handle a booking, exchange practical messages |
| B1 | Independent communication about familiar matters | Tell an original story, explain plans and reasons, handle a travel complication, follow a longer account |
| B2 | Sustained discussion and detailed communication | Compare viewpoints, negotiate a solution, discuss reports, write an argument with supporting detail |
| C1 | Flexible communication across demanding contexts | Interpret implied meaning, adapt register, synthesise sources, present and defend a developed position |
| C2 | Precise and nuanced handling of complex communication | Reconcile subtle viewpoints, reformulate difficult material, analyse tone, produce polished communication for a specific audience |

C2 is not a promise of knowing every word or being indistinguishable from a native speaker. Advanced learning needs depth, variation and repeated performance, not an ever-larger phrase list.

## Lesson and activity structure

Each module follows the same understandable cycle, with different task complexity and support:

1. **Learn:** teach required language, patterns and communication strategies in context.
2. **Practise with support:** examples, slower playback, glosses and guided responses.
3. **Apply:** use that language to achieve a goal with several valid outcomes.
4. **Try independently:** a new version of the situation without an answer shown beforehand.
5. **Get feedback and revisit:** explain what worked, identify a specific gap and schedule suitable practice.

Track prerequisites explicitly. Do not demand an untaught word or construction merely because a learner reached an activity's position in the path. For beginner independent checks, vary situations using taught language. Later inference tasks may include unfamiliar expressions only where interpreting them is the taught skill and the task has been reviewed for that purpose. Hint use affects the evidence recorded; it does not punish or prevent practice.

Maintain the approved Wordami illustration style. Higher levels need more substantial tasks and material; decorative complexity should not determine difficulty. Beginner scenes can evolve into longer exchanges, documents, presentations, discussions and source comparisons.

## Assessment and progress

- Keep XP/streaks, FSRS memory state, curriculum completion and demonstrated language performance separate.
- Keep results per language and skill. A strong reading result cannot silently fill a missing speaking result.
- Store activity version, assessed objective, prerequisite version, assistance used, first attempt versus replay, response/evidence, scorer version and review status.
- Use several fresh tasks and repeated evidence; one successful café visit cannot award A1 or A2.
- Assess spoken and written meaning, task success, organisation, range, accuracy and appropriateness where relevant. Transcript similarity is insufficient for free responses.
- AI may provide practice feedback, but any proficiency scoring needs reviewed rubrics, calibration and quality checks. Select the service and privacy design during implementation, before recording or uploading new learner evidence.
- Keep unreviewed, unavailable or unassessed skills visibly distinct from demonstrated skills. Do not publish arbitrary CEFR percentages, automatic XP conversions or exam-equivalence claims.

## Build sequence and release gates

### Foundation — current work

Create an objective map for A1 in both courses, link existing teaching sources, identify missing task types and define the first assessment rubrics. Preserve current item IDs, PATH order, saved progress and live Lithuanian access. The new A1 map is planning metadata, not an enforced reorder or learner score.

### First complete level — A1

Use Lithuanian as the first end-to-end implementation and carry the same activity contracts into Spanish. Implement practical reading and listening tasks, short original writing, and supported then independent speaking. Begin with identity, food, directions, time and arrangements. Use more than one version of each task, and audit their language prerequisites. Complete language review and learner trials before claiming full A1 coverage or achievement. Finish Spanish editorial review before its public rollout.

Release gate: reviewed descriptor-to-teaching-to-practice-to-assessment coverage for the chosen A1 profile, working accessibility and offline behaviour where supported, tested progress migration, and calibrated evidence for every claimed skill. Thresholds must be established through assessment design and trials; this plan does not invent pass marks.

### A2

Expand the existing everyday topics into longer sequences, changed details, practical problems, short accounts and more flexible messages. Keep beginner review available. Assess understanding and task completion, rather than only expected sentence recall.

Release gate: close A2 coverage gaps, validate independent tasks and repeat evidence requirements, and review both language adaptations separately.

### B1

Build connected stories, explanations, follow-up questions, repair strategies and independent responses to complications. Increase listening/text length and response freedom without assuming that the presence of past-tense cards establishes B1.

Release gate: varied independent performance across the intended B1 profile with calibrated speaking and writing assessment.

### B2

Add sustained discussion, negotiation, viewpoints, extended reading/listening and structured writing. Source or commission varied material, with permission to distribute it. Include different speakers and appropriate language varieties; validate teaching quality rather than relying on synthetic audio alone.

### C1 and C2

Commission advanced language-specific curricula and expert-reviewed material: register, implication, idiomatic use, detailed source synthesis and precise reformulation. Build longer tasks, portfolios and expert moderation for advanced assessment. Both languages require their own progression and cultural contexts; translated copies of a single syllabus are insufficient.

Release gates for B2–C2: expert curriculum and language review, appropriate content rights, varied material, level-specific assessment trials, scorer calibration and evidence sufficient for the claims made.
