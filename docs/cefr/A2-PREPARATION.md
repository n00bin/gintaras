# A2 teaching and writing preparation

The A2 pass covers four connected units per language: changing a plan, appointments, a working day and a group meal. It adds explicit source-language preparation and project-specific writing support while preserving existing drafts and results.

## Source language before tasks

The exact-form audit identified forms in reading, listening and partner questions that were beyond explicit preparation in earlier units. The new support adds 121 contextual explanations in Lithuanian and 90 in Spanish. Previously explained forms are reused rather than listed again in every unit.

These 211 entries are contextual forms, not 211 dictionary headwords or new scheduled vocabulary cards. They include inflections, time expressions, question words, polite instructions, conditions and useful constructions. Every entry has a meaning and an exact sentence from the unit where it occurs. The automated cumulative-form audit now reports no unprepared target-language forms in the A1–A2 sources it checks; this does not establish linguistic accuracy or mastery.

A2 source preparation is required before its comprehension and productive tasks. A missing support file or a failed save does not mark the new preparation complete. Earlier A1 records retain their existing identities. Previously completed A2 reading, listening, speaking and writing results stay saved; learners study only the added source material to restore access. A missing A2 file does not disable completed A1 work.

## Twelve A2 writing models

The six projects per language now include worked models, three guided purpose exercises and saved planning fields:

| Project | Learning focus |
| --- | --- |
| Day out | Sequence, reaction and reason |
| Changed arrangement | Problem, alternative and confirmation |
| Place recommendation | Activity, reason and practical detail |
| Changed booking | Original appointment, replacement request and confirmation |
| Team update | Temporary change, timing, responsibilities and a condition for help |
| Meal update | Changed details, unchanged requests and confirmation |

All twelve new models use forms with earlier explicit preparation. A2 models connect ideas and explain relationships rather than merely list personal facts. Guided practice asks which line gives a particular piece of useful information, and explains correct choices. It does not award independent skill credit.

The suggested practice ranges fit the actual short models: approximately 15–90 words depending on language and task. Compact Lithuanian arrangements and recommendations can fulfil their purpose in fewer words. These are authoring suggestions, not CEFR thresholds. Source review books show each project's effective range and complete model.

Saved plans, text exports and the existing draft/review workflow work for A2 as for A1. Original unit content signatures and project IDs are unchanged. The combined A1–A2 support now contains twenty-four models and seventy-two guided purpose exercises across both languages.
