# Curriculum breadth: evidence and remaining work

This checklist makes the remaining work concrete. It is informed by Chapters 3–5 of the [CEFR Companion volume](https://rm.coe.int/cefr-companion-volume-with-new-descriptors-2020/16809ea0d4), uses authored task-family labels and contains no official descriptor quotations. A linked task is an implemented example, not proof that a complete scale or level is covered. Signing competence is outside this spoken/written course profile.

## Review and implementation order

1. Review each band’s prepared language and actual sources, using the exact-version review books. Resolve incorrect or prematurely introduced forms.
2. Add missing practical document and sustained-input tasks with explicit teaching, source guides and task-specific criteria. Link them to their units and preserve previous work.
3. Broaden speaker, genre, discourse and interaction demands; include different occasions and genuine transfer.
4. Collect independently judged speech/writing and live-interaction evidence; calibrate reviewers and run learner trials.
5. Reconcile the full public course candidate, accessibility review and deployment checks. The current live image release remains usable while this work continues.
